# Recording consent (template)

Signed copies are kept off the repository. This template exists so the README can point at the exact language used.

**Project:** Lugha, a hackathon project that detects moments in the wearer's own speech where communication broke and was repaired, and turns them into short lessons for the wearer.

**Who records:** the wearer, using a Bee wearable on an Apple Watch, in Massachusetts. Massachusetts requires all parties to consent to recording.

**What is recorded:** audio of conversations the wearer takes part in. Bee transcribes the audio. Lugha reads the transcript.

**What Lugha keeps:** only the wearer's own utterances. Other speakers' words are read once to decide whether a repair happened, then discarded. They are never stored, logged, or shown.

**What may appear publicly:** short clips in a demo video, only from conversations where every participant signs this form. Names can be replaced on request.

**Withdrawal:** any participant may ask for their conversation to be removed from the demo at any time before submission.
