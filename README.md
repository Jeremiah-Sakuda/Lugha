# Lugha

Lugha turns the English you struggled with today into the lesson you remember tomorrow.

An adult English learner wears Bee on an Apple Watch through an ordinary day. Lugha listens to the transcript for moments where communication broke and was repaired ("sorry?", a rephrase, a self-correction), and after the conversation ends it delivers a four-line lesson built from the learner's own words. Over weeks it shows which patterns keep recurring and which have not been seen since a date. It never interrupts, never scores, and never keeps anyone's words but the wearer's.

Built for the Amazon Developer Hackathon 2026, Bee (Wearable AI) track, with the `repairs` detector as the Open Source mini-challenge contribution.
